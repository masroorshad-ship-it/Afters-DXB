# Lumora (demo)

A static, fictional stablecoin-payments dashboard for demonstration only.
All names, balances and transactions are sample data — this is not a real account or service.

## Run

Open `index.html` in a browser (no build step), or serve the folder, e.g. `npx serve .`.

Demo login: `abc@gmail.com` / `Abc@94`

## Features

- Login page (only the demo credentials above are accepted), log out
- Overview: balance card, quick actions, totals, cash-flow chart, receiving info, recent transactions
- Transactions page with filters (Deposits, Withdrawals, Fees, Pending, Completed, Failed)
- Simulated USDT withdrawal (stored in browser localStorage; reset from Settings)
